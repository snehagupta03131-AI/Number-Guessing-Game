# Number Guessing Game 🔢

A simple Number Guessing Game built using Python.

## About the Project

In this game, the computer generates a random number and the player tries to guess it. The program provides feedback to help the player find the correct number.

## Technologies Used

- Python
- Jupyter Notebook

## Features

- Random number generation
- User input
- Guess validation
- Helpful feedback
- Simple and interactive gameplay

## How to Run

1. Open `project2.ipynb` in Jupyter Notebook.
2. Run the cells.
3. Enter your guess.
4. Follow the hints provided by the program.
5. Continue until you guess the correct number.
